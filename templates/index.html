Keylogger Educativo

Captura pulsaciones de teclas — Demuestra riesgos de espionaje de teclado

📚 Para diseñar un anti-keylogger es necesario entender cómo funciona un keylogger. Este módulo usa la librería keyboard de Python para capturar lo que se escribe en el teclado y reconstruir el texto.

💡 Al presionar el botón, el keylogger capturará todas las teclas que presiones durante el tiempo indicado. Escribe algo en cualquier programa para ver cómo se registra.

Servidor de Archivos — Máquina Víctima

Conéctate a la IP de la víctima para ver y descargar los archivos que subió con arch.py

🎯 La máquina víctima debe correr arch.py (puerto 5001). Escribe su IP, presiona Conectar y podrás ver y descargar todos los archivos que subió. El servidor actúa como proxy para evitar bloqueos del navegador.

Ejecuta esto en la máquina víctima para levantar el servidor:

python arch.py
